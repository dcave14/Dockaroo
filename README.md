# Dockaroo

Groups of shortcuts behind single taskbar buttons, for Windows 11.

Each group gets its own pinned taskbar button. Clicking it opens a small popup of the group's
apps, centred on the button and styled like the taskbar. Dockaroo runs as one resident tray
process, so the popup opens instantly: nothing is read from disk on a click.

- Groups are edited in the built-in editor (tray icon > Edit groups...).
- Five logo palettes, light and dark (Appearance page).
- Imports groups from the legacy app it replaces (editor > Import).
